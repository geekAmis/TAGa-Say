# Боты TAGa-Say

Сервисы, работающие через Bot API. Каждый бот — отдельный процесс/контейнер, не часть APK.

| Бот | Статус | Описание |
|---|---|---|
| [enchat-bridge](enchat-bridge/) | alpha | Мост в публичные комнаты Enchat |

## Принципы

- Бот не имеет доступа к ключам E2EE и истории чата.
- Бот видит только адресованные ему сообщения (privacy mode).
- Токены — только в secret manager, не в образе и не в репозитории.
- Логи не содержат текст сообщений.
- Для сторонних сервисов соблюдаем их лицензии: Enchat © sudodevdante
