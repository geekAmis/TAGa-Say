# E2E peer

Небольшой JVM-клиент на libsignal, который используется для сквозного теста
TAGa-Say без второго телефона.

Он:

- регистрирует второго пользователя (`anna`) на relay;
- генерирует настоящие Signal identity/prekeys (X3DH + PQXDH);
- принимает и расшифровывает сообщения от мобильного клиента;
- умеет отправлять зашифрованные сообщения на телефон.

## Запуск

```bash
cd tools/e2e-peer
gradle run --args="http://127.0.0.1:8080 anna Anna"
```

Переменные:

- `PEER_SEND` — отправить сообщение `@lilanga` сразу после регистрации;
- `PEER_HOLD=1` — не завершаться после отправки (нужно для приёма);
- `PEER_AUTOREPLY` — автоответ на каждое входящее.

Для телефона relay доступен через `adb reverse tcp:8080 tcp:8080`, а debug-сборка
по умолчанию использует `http://127.0.0.1:8080`.

Этот инструмент не входит в APK и нужен только для разработки/QA.
