# Contributing

Спасибо за интерес к TAGa-Say.

## Правила

1. Криптография — только через `core/crypto`, без самодельных примитивов.
2. Новый код — с тестами; критические модули (ratchet, KDF, парсеры) — с покрытием.
3. Форматирование: `ktlint` + `detekt`.
4. Коммиты — Conventional Commits (`feat:`, `fix:`, `docs:`…).
5. Перед PR: `./gradlew check`.

## Ветки

- `main` — стабильная;
- `dev` — интеграция;
- `feat/<scope>` — фичи;
- `fix/<scope>` — исправления.

## Безопасность

Не открывайте публичные issue об уязвимостях — см. [SECURITY.md](SECURITY.md).

## Лицензия

Отправляя PR, вы соглашаетесь с условиями MIT и подтверждаете, что имеете право
передать код проекту.
