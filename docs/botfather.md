# @BotFather — матрица паритета (сервер 1.2.0)

`@BotFather` — встроенный бот платформы TAGa-Say: обычный бот с
`builtin=true`, без внешнего токена и webhook, работает через те же
`BotService`/`BotStore`, что и остальные боты. В каталоге — verified.

- Username `botfather` зарезервирован (case-insensitive), удалить нельзя.
- Первый контакт: клиент открывает чат и отправляет `/start` (иначе действует
  общий `/start`-gate).
- FSM на владельца хранится в `bots.json` и переживает рестарт; таймаут
  диалога 20 минут → сброс с подсказкой `/help` и `/cancel`.
- `callback_data` ≤64 байт: `bf:<action>:<botId|->:<hmac8>`, подпись
  привязана к владельцу, действию и botId; данные кнопки не считаются
  доверенными.
- Лимит 20 активных ботов на владельца; Busy/reserved username отклоняются
  с человеческим текстом, ввод не теряется.
- Токен показывается только по явному действию (создание, `/token`, `/revoke`);
  в логи/audit не попадает.

## 4. Отличия и решения

1. **Username освобождается сразу** после удаления (ADR-009); старые токены
   остаются отозванными, данные бота живут до 30 дней. В Telegram username
   освобождается не сразу — отличие осознанное, задокументировано.
2. **Список команд** — глобальный; `scope`/`language_code` принимаются, но
   игнорируются до P1.
3. **`/token`** показывает предупреждение и токен в одном сообщении (явное
   действие пользователя), а не отдельным экраном-подтверждением.
4. **`/setcommands` с пустым списком** не очищает команды (Telegram требует
   отдельного подтверждения) — используйте Bot API `deleteMyCommands`.
5. **`/deletebot`** требует ввести `@username` — защита от случайного удаления.
6. **Миграция**: если username `botfather` уже занят реальным ботом,
   встроенный BotFather не создаётся, в лог пишется предупреждение; данные
   никого не переименовываются молча (безопасный план — ADR-004/ТЗ §7.4).

## 5. Ручной сценарий проверки

1. Открыть чат `@BotFather` → `/start`.
2. `/newbot` → имя → `my_test_bot` → получить токен.
3. `/mybots` → карточка → «Токен» → тот же токен.
4. `/setcommands` → `ping - Проверка` → `/mybots` → карточка показывает 1 команду.
5. `/revoke` → подтвердить → новый токен; старый `getMe` → 401.
6. `/deletebot` → ввести `@my_test_bot` → бот удалён; `getMe` → 401.
7. `/cancel` в любом шаге → диалог сброшен.
8. Подождать 20 минут в шаге → следующее сообщение сбрасывает диалог.

## 6. Что осталось `[~]`

- Скриншоты живого Telegram и точные тексты-эталоны.
