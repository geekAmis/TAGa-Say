## Правила

- Секреты не коммитятся: `prompt.txt`, `.env`, `keystore.properties`, `*.jks`,
  API-ключи. Для сервера — `/etc/tagasay/aeza.env` с правами `600`.
- Release-сборка использует relay, зашитый при сборке; смена сервера из UI
  недоступна.
- Перед работой с реальными чувствительными данными — внешний аудит
  (см. `docs/release.md`).
