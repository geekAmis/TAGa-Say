# TAGa-Say 1.3.0

Группы и каналы с серверной доставкой.

## Что работает

- Серверные комнаты: создание, участники, роли, join/leave, обновление.
- Группа создаётся из контактов; участников можно добавлять и удалять.
- Каналы: владелец/админ публикует, подписчики читают.
- Pairwise fan-out: каждому участнику уходит отдельный E2EE-конверт.
  Сервер видит только метаданные комнаты и ciphertext.
- Приглашение `TYPE_ROOM` создаёт групповой чат у участника.
- Список комнат синхронизируется при старте.
- Недоступный участник не ломает отправку остальным.
- Сервер не добавляет пользователя без зарегистрированного устройства.

## Безопасность

- E2EE 1:1 не изменён.
- Комнаты не получают ключи/state/контакты пользователя.
- Добавление в комнату проверяет owner/admin на сервере.
- В канал пишет только owner/admin (проверка на клиенте и сервере по правам).
- State push больше не отправляется каждые 16 секунд из-за нестабильного timestamp.

## Ограничения

- Нет Sender Keys: стоимость отправки O(участников), сервер видит граф комнаты.
- Нет истории для нового участника.
- Медиа/реакции/опросы в группах — следующий этап.
- Звонки всё ещё демо-экран без WebRTC.
- Мультиустройство и восстановление master-ключа — следующий этап.
